# ButovskyHOST

Telegram-бот для заявок на аренду серверов на `aiogram 3`.

## Возможности

- регистрация пользователя при `/start` в `data/users`;
- профиль с именем, фамилией, Telegram ID и статусом;
- каталог серверов пользователя из `data/servers`;
- заказ с выбором региона, тарифа, срока, разрешения на использование до 20% мощности и решения;
- отображение реквизитов, расчёт цены и загрузка фото/файла чека;
- сохранение заказов в `data/orders`;
- уведомление администратора с чеком и кнопками проверки оплаты;
- этапы заказа: `Заказан` → `Настройка` → `Готов`;
- ввод IP, порта, логина, пароля и комментария при выдаче сервера;
- управление тарифами и ценами из админ-панели;
- изменение платёжных реквизитов из админ-панели;
- статистика пользователей, заказов, дохода и готовых серверов;
- просмотр администратором всех выданных серверов, включая доступы и разрешение 20%.

## Быстрый запуск

Нужен Python 3.10 или новее.

```bash
chmod +x start.sh
./start.sh
```

При первом запуске скрипт запросит Telegram ID администратора и токен бота,
создаст локальный `.env`, установит зависимости и запустит polling.

Токен хранится только в `.env`, который добавлен в `.gitignore`. Не отправляйте
его в GitHub и не публикуйте в чате.

## Запуск после перезагрузки VPS

Для установки systemd-сервиса выполните один раз:

```bash
sudo ./start.sh --install-service
```

Сервис будет включён в автозапуск и перезапускаться при падении процесса.

Полезные команды:

```bash
sudo systemctl status butovskyhost
sudo journalctl -u butovskyhost -f
sudo systemctl restart butovskyhost
```

Если запуск выполняется от обычного пользователя, путь проекта не должен быть
доступен другим пользователям: `.env` содержит токен бота и создаётся с правами
`600`.

## Первый запуск бота

1. Откройте бота с аккаунта администратора и выполните `/start`.
2. Откройте `⚙️ Админ-панель`.
3. В разделе `💳 Тарифы` добавьте тариф и цены за 1, 3 и 5 месяцев.
4. В разделе `💰 Реквизиты` укажите реквизиты для оплаты.
5. Проверьте пользовательский сценарий: выбрать тариф, отправить чек,
   подтвердить оплату, перевести заказ в настройку и выдать сервер.

## Структура данных

```text
data/
├── users/       # пользователи, один JSON на Telegram ID
├── tariffs/     # тарифы, один JSON на тариф
├── orders/      # заказы и сведения о чеках
├── servers/     # готовые серверы с доступами
└── settings.json
```

Каждая запись сохраняется атомарно через временный файл и `os.replace`, чтобы
перезапуск во время записи не оставил частичный JSON. Реальные данные в этих
папках не коммитятся благодаря `.gitignore`.
